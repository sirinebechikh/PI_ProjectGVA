# 🚀 MeetNTrip_Desktop

Application **JavaFX Desktop** permettant la gestion complète d’une plateforme d’événements, avec forum collaboratif, système de réservation, et gestion des utilisateurs.

Développée dans le cadre d’un projet académique à **ESPRIT** par ****Code Masters****

---

## 🧩 Modules Fonctionnels

### 📅 Événements
- Ajout / modification / suppression
- Affichage sous forme de cartes modernes
- Affectation d’employés
- Validation par un administrateur

### 👥 Utilisateurs
- Authentification (login / signup)
- Rôles : Admin / Client / Employé/Sponsar
- Gestion du profil utilisateur

### 💬 Forum
- Création de publications
- Commentaires dynamiques
- Système de likes
- Recherche et filtrage

### 📌 Réservations
- Réserver une place à un événement
- Annulation d’une réservation
- Historique des réservations

---

## 🛠️ Stack Technique

| Technologie      | Description                        |
|------------------|------------------------------------|
| Java 17          | Langage principal                  |
| JavaFX / FXML    | Interfaces utilisateur             |
| Scene Builder    | Design graphique des vues          |
| MySQL / XAMPP    | Base de données relationnelle      |
| JDBC             | Connexion Java ↔ Base de données   |
| MVC              | Architecture du projet             |
| CSS externe      | Personnalisation graphique         |
